# API scratch program

```text
javac LibraryLab.java
java LibraryLab
```

[LibraryLab.java](LibraryLab.java) contains a die sample and unfinished player
and game sections. [CLASSES.md](CLASSES.md) documents the API.

## Sections

- A: current die value, a roll, and the stored result.
- B: two players, their names and scores, and a five-point change to one player.
- C: a game using one player; add 4, add 6, bank, advance, add 3, lose the turn.

`showState()` prints the label, turn score, banked score, and turn-over status.
